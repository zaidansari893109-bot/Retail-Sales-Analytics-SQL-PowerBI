# Retail Sales Performance & Insights Dashboard

## 📌 Project Overview

This project focuses on analyzing retail sales data using MySQL and Microsoft Power BI. The main goal is to understand sales performance, profitability, product trends, customer behavior, and discount patterns through SQL queries and interactive dashboards.

The project demonstrates how data analytics tools can transform raw retail data into meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze total sales, profit, and quantity sold.
- Identify top-performing products and categories.
- Compare sales performance across states and cities.
- Analyze customer segments and payment methods.
- Understand discount patterns across product categories.
- Examine monthly sales trends.
- Evaluate store-type performance.
- Generate insights to support business decisions.

## 🛠️ Tools and Technologies

- **MySQL:** Data querying, filtering, grouping, aggregation, and analysis.
- **Microsoft Power BI:** Interactive dashboards, KPI cards, charts, and data visualization.

## 📊 Dashboard Pages

### 1. Retail Sales Performance Dashboard
Provides an overview of total sales, total profit, total orders, quantity sold, category performance, state-wise sales, product performance, and monthly sales trends.

### 2. Detailed Analysis
Examines payment methods, city-wise sales, category-wise profit, and product quantity sold.

### 3. Sales Insights
Explores monthly sales trends, state-wise profit, store-type performance, and customer segments.

### 4. Customer & Discount Analysis
Analyzes customer segments, category-wise discounts, customer profitability, and average discounts by store type.
