# Retail Sales Performance & Insights Dashboard

## Project Overview
This project analyzes retail sales data using SQL and Power BI to identify business trends and generate meaningful insights.

## Objectives
- Analyze total sales and profit.
- Identify top-performing products and categories.
- Compare sales across states and cities.
- Analyze customer segments and payment methods.
- Understand discount patterns and shipping modes.
- Support data-driven business decisions.

## Tools Used
- MySQL — Data analysis using SQL queries
- Microsoft Power BI — Interactive dashboards and visualizations

## Project Files
- `Retail sales project.sql zaid.sql` — SQL queries used for analysis
- `Retail Sales Performance & Insights Dashboard.pbix` — Power BI dashboard

## Dashboard Pages
1. Retail Sales Performance Dashboard
2. Detailed Analysis
3. Sales Insights
4. Customer & Discount Analysis

## Key Business Metrics
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold

## Conclusion
This project demonstrates how SQL and Power BI can be used together to analyze retail data, identify patterns, and support business decision-making.
